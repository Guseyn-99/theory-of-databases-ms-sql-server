# 📘 Конспект 1 — Архитектура базы данных Microsoft SQL Server

## 1. Что такое СУБД

**СУБД (система управления базами данных)** — программное обеспечение, которое позволяет:

- создавать базы данных;
- хранить данные;
- изменять и удалять данные;
- выполнять запросы;
- обеспечивать целостность данных;
- работать с несколькими пользователями одновременно;
- управлять безопасностью и доступом.

В нашем случае используется Microsoft SQL Server.

---

## 2. SQL Server

SQL Server состоит из нескольких основных компонентов.

С помощью SQL Server можно:

- создавать базы данных;
- создавать таблицы;
- задавать связи между таблицами;
- выполнять SQL-запросы;
- управлять пользователями и правами;
- работать с транзакциями;

---

## 3. Аутентификация и авторизация

При подключении к SQL Server необходимо определить, кто подключается и что этому пользователю разрешено.

**Аутентификация**

Аутентификация — проверка личности пользователя.

То есть: «Кто ты?»

**Авторизация**

Авторизация — определение разрешений пользователя.

То есть: «Что тебе разрешено делать?»

Например, пользователь может иметь право:

- читать данные;
- изменять данные;
- создавать таблицы;
- создавать базы данных.

---

## 4. Экземпляр SQL Server

**Экземпляр (Instance)** — отдельная установленная и запущенная копия SQL Server.

К одному компьютеру может быть привязано несколько экземпляров SQL Server.

При подключении указывается, к какому экземпляру необходимо подключиться.

---

## 5. Системные и пользовательские базы данных

SQL Server содержит системные базы данных.

Основные:

**master** — содержит важную системную информацию SQL Server:

- сведения об экземпляре;
- базы данных;
- настройки;
- учетные записи и т.д.

**model** используется как шаблон при создании новых баз данных.

**msdb** используется SQL Server для различных служебных задач.

Например, для хранения информации о заданиях и автоматизированных операциях.

**tempdb** — временная база данных.

Используется SQL Server для хранения временных объектов и промежуточных результатов.

**Resource**

Содержит системные объекты SQL Server.

---

## 6. Пользовательские базы данных

Это базы данных, которые создаёт разработчик или администратор.

Например, наша база:

**BSTU**

Именно внутри неё мы создавали таблицы:

`FACULTY`, `PROFESSION`, `PULPIT`, `TEACHER`, `GROUPS`, `STUDENT`, `SUBJECT`, `PROGRESS`, `AUDITORIUM`, `AUDITORIUM_TYPE`

---

## 7. Хранение данных

SQL Server хранит информацию не просто «одним большим файлом».

Используются:

**страницы → экстенты → файлы → файловые группы**

**Страница (Page)** — минимальная единица хранения данных в SQL Server.

Размер страницы SQL Server — **8 КБ**.

**Экстент (Extent)** — группа из нескольких страниц.

Один экстент содержит **8 страниц**.

---

## 8. Файлы базы данных

База данных SQL Server может состоять из нескольких физических файлов.

Основные типы:

**MDF** — основной файл базы данных.

Например:

`BSTU.mdf`

**NDF** — дополнительный файл базы данных.

Например:

`BSTU_2.ndf`

Можно использовать несколько дополнительных файлов.

**LDF** — файл журнала транзакций.

Например:

`BSTU_log.ldf`

---

## 9. Filegroup — файловая группа

**Filegroup** — логическая группа файлов базы данных.

Она позволяет организовывать файлы базы данных.

Например:

```text
FG1
├── BSTU_1.ndf
└── BSTU_2.ndf
```

При создании базы данных можно указать:

- имя базы;
- расположение файлов;
- размер;
- максимальный размер;
- файловую группу.

---

## 10. Создание базы данных

Общий принцип:

```sql
CREATE DATABASE имя_базы
```

Можно также указать файлы:

```sql
CREATE DATABASE BSTU
ON
(
    NAME = BSTU,
    FILENAME = 'C:\BD\BSTU.mdf'
)
LOG ON
(
    NAME = BSTU_log,
    FILENAME = 'C:\BD\BSTU_log.ldf'
);
```

В более сложном варианте можно создавать несколько файлов и файловые группы.

---

## 11. Изменение базы данных

Для изменения существующей базы используется:

```sql
ALTER DATABASE
```

Например, можно:

- добавить файловую группу;
- добавить файл;
- изменить параметры базы.

---

## 12. Удаление таблицы

Для удаления таблицы:

```sql
DROP TABLE имя_таблицы;
```

⚠️ `DROP TABLE` удаляет саму таблицу вместе с её данными.

---

## 13. Изменение структуры таблицы

Для изменения существующего объекта используется:

```sql
ALTER TABLE
```

С его помощью можно изменять структуру таблицы.

---

## 14. Системный каталог

SQL Server хранит информацию о своих объектах в системном каталоге.

Можно получить информацию о:

- таблицах;
- столбцах;
- ограничениях;
- объектах базы данных.

Также используется стандарт `INFORMATION_SCHEMA`.

Например:

```sql
INFORMATION_SCHEMA.TABLES
```

позволяет получить информацию о таблицах.

---

## 15. Системные процедуры и функции

SQL Server предоставляет встроенные процедуры и функции для получения служебной информации и выполнения различных операций.

В презентации отдельно рассматриваются:

- системные хранимые процедуры;
- системные функции.

---

## Главное из презентации

Нужно понимать цепочку:

```text
SQL Server
    ↓
Экземпляр
    ↓
База данных
    ↓
Файлы
    ↓
Таблицы
    ↓
Данные
```

И основные понятия:

| Термин | Что означает |
|---|---|
| SQL Server | СУБД Microsoft |
| Instance | Экземпляр SQL Server |
| Database | База данных |
| MDF | Основной файл БД |
| NDF | Дополнительный файл |
| LDF | Журнал транзакций |
| Filegroup | Группа файлов |
| Page | Страница хранения |
| Extent | Группа страниц |
| master | Системная БД |
| model | Шаблон для новых БД |
| msdb | Служебная БД |
| tempdb | Временная БД |

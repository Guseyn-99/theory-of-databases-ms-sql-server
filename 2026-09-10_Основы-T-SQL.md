# 📙 Конспект 2 — Основы T-SQL

## 1. Что такое T-SQL

**T-SQL (Transact-SQL)** — расширение SQL для Microsoft SQL Server.

Помимо обычных SQL-запросов, T-SQL позволяет использовать:

- переменные;
- условия;
- циклы;
- функции;
- процедуры;
- обработку ошибок.

---

## 2. Переменные

Переменная хранит значение.

### Объявление

```sql
DECLARE @name тип;
```

Например:

```sql
DECLARE @count INT;
```

Можно сразу присвоить значение:

```sql
DECLARE @count INT = 10;
```

### Изменение значения

```sql
SET @count = 20;
```

Также можно присваивать значение через `SELECT`:

```sql
SELECT @count = 20;
```

### Вывод

```sql
PRINT @count;
```

**Чаще всего:** `DECLARE`, `SET`, `SELECT`.

---

## 3. Преобразование типов

Используются:

```text
CAST
CONVERT
```

### CAST

```sql
CAST(значение AS тип)
```

### CONVERT

```sql
CONVERT(тип, значение)
```

Они нужны, когда необходимо преобразовать значение из одного типа в другой.

---

## 4. Условия

### IF / ELSE

Используется, когда нужно выполнить разные действия в зависимости от условия.

```sql
IF условие
BEGIN
    -- действия
END
ELSE
BEGIN
    -- действия
END
```

**Очень часто используется в T-SQL.**

---

## 5. CASE

`CASE` позволяет получить разный результат в зависимости от условия.

```sql
CASE
    WHEN условие THEN результат
    ELSE результат
END
```

Особенно часто встречается прямо внутри `SELECT`.

---

## 6. Цикл WHILE

Используется для многократного выполнения действий.

```sql
WHILE условие
BEGIN
    -- действия
END
```

Например, цикл выполняется, пока условие является истинным.

---

## 7. Работа с датами

Самые важные функции:

### DATEADD

Добавляет время к дате.

```sql
DATEADD(часть_даты, число, дата)
```

### DATEPART

Получает часть даты.

```sql
DATEPART(часть_даты, дата)
```

Например, можно получить год или месяц.

### DATEDIFF

Вычисляет разницу между датами.

```sql
DATEDIFF(часть_даты, дата1, дата2)
```

### Как запомнить

```text
DATEADD   → добавить
DATEPART  → получить часть
DATEDIFF  → разница
```

---

## 8. Обработка ошибок

Используется конструкция:

```sql
BEGIN TRY
    -- код
END TRY
BEGIN CATCH
    -- обработка ошибки
END CATCH
```

Если в `TRY` возникает ошибка, управление переходит в `CATCH`.

Также в презентации рассматривается:

```text
RAISERROR
```

для формирования сообщения об ошибке.

---

## 9. Курсоры

Курсор позволяет последовательно обрабатывать строки результата.

Основные команды:

```text
DECLARE → OPEN → FETCH → CLOSE → DEALLOCATE
```

Для начала достаточно запомнить саму последовательность.

---

## 10. Программные объекты SQL Server

В SQL Server можно создавать:

### Хранимые процедуры

**Procedure** — сохранённый набор инструкций T-SQL.

### Функции

Возвращают значение или набор данных.

### Триггеры

Автоматически выполняются при определённых действиях с данными.

---

## Полезная мини-шпаргалка

```text
DECLARE   — создать переменную
SET       — присвоить значение
SELECT    — получить/выбрать данные

IF        — если
ELSE      — иначе
CASE      — выбор результата
WHILE     — повторять

CAST      — преобразовать тип
CONVERT   — преобразовать тип

DATEADD   — прибавить к дате
DATEPART  — взять часть даты
DATEDIFF  — найти разницу дат

TRY/CATCH — обработать ошибку

CURSOR    — идти по строкам
PROCEDURE — сохранённый набор команд
FUNCTION  — функция
TRIGGER   — автоматическая реакция на действие
```

# Практическая работа по БД — 17.09.2026

## Задание

Создать собственную базу данных минимум с 5 таблицами, связать таблицы между собой (кроме одной), получить по одной строке из каждой таблицы с помощью T-SQL и загрузить материалы в репозиторий.

## Что сделано

Создана база данных `CompanyDB` из 6 таблиц:

- `Departments` — основная таблица;
- `Positions` — связана с `Departments` через `DepartmentId`;
- `Employees` — связана с `Positions` через `PositionId`;
- `Projects` — связана с `Employees` через `EmployeeId`;
- `Logs` — отдельная таблица без внешних ключей.

Таким образом, 5 таблиц участвуют в связанной структуре, а `Logs` является отдельной таблицей.

Для получения данных использованы запросы `SELECT TOP 1 *` для каждой таблицы.

# БД — домашняя работа 18.09.2026

## Задание
Создать хранимую процедуру и функцию в T-SQL.

- Функция показывает примеры встроенных строковых, математических, дата-временных и системных функций.
- Процедура `DIFF_STUDENTS` считает разницу между поступившими студентами (1 курс) и выпускающимися (4 курс).
- После обновления группы `IDGROUP = 301` выполнен повторный вызов процедуры.

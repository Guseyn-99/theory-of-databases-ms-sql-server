\# Теория баз данных. Программирование MS SQL Server



Учебный репозиторий по дисциплине \*\*«Теория баз данных. Программирование MS SQL Server»\*\*.



\## Структура репозитория



\### `homework/`

Домашние работы.



Каждая работа находится в отдельной папке и содержит:

\- `README.md` с кратким описанием задания;

\- скриншоты выполнения;

\- SQL-файлы;

\- исходные материалы, если они были нужны для работы.



\### `practice/`

Практические работы, выполненные на занятиях.



В папках могут находиться:

\- SQL-скрипты;

\- скриншоты выполнения;

\- README с описанием работы;

\- исходные файлы преподавателя.



\### `theory/`

Теоретические материалы и конспекты по дисциплине.

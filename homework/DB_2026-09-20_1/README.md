# Сравнение способов группировки в MS SQL Server

## Задание

Сравнить основные способы группировки данных в MS SQL Server и показать их работу на примерах.

Рассмотрены:

- `GROUP BY`
- `GROUP BY + HAVING`
- `ROLLUP`
- `CUBE`
- `GROUPING SETS`
- `PARTITION BY`

## Кратко

- `GROUP BY` — базовая группировка строк.
- `HAVING` — фильтрация уже сгруппированных данных.
- `ROLLUP` — иерархические подытоги и общий итог.
- `CUBE` — все возможные комбинации группировок.
- `GROUPING SETS` — выбор конкретных наборов группировок.
- `PARTITION BY` — агрегирование без сворачивания строк.

## Результат

В работе приведены примеры запросов, результаты их выполнения, плюсы и минусы каждого способа, а также итоговое сравнение.
